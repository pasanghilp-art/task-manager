# ✅ Task Manager App — Pasang Tamang

A colorful and fun task manager app with priority levels built with vanilla HTML, CSS, and JavaScript.

## 🔗 Live Demo
[pasanghilp-art.github.io/task-manager](https://pasanghilp-art.github.io/task-manager)

## 📸 Features
- Add tasks with 3 priority levels (High, Medium, Low)
- Complete and delete tasks
- Filter tasks by priority or completion status
- Tasks persist on page refresh using localStorage
- Stats row showing total, high priority, medium, and done counts
- Colorful and fun UI with smooth animations
- Fully responsive on all screen sizes

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript (Vanilla)
- localStorage (data persistence)
- Google Fonts (Nunito)
- GitHub Pages (deployment)
